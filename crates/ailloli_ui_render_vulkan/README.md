# ailloli_ui_render_vulkan

Experimental Vulkan and SPIR-V renderer for immersive Ailloli UI hosts.

This beta crate targets Rust 1.88. The primary desktop renderer remains
`ailloli_ui_render_wgpu`; Vulkan integration may change more quickly.
