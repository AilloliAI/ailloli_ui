# ailloli_ui_devtools_core

Backend-neutral inspection snapshots, diagnostics, and optional terminal
observability contracts for Ailloli UI DevTools.

This beta crate targets Rust 1.88. Most applications should enable DevTools
through the `ailloli_ui` façade.
