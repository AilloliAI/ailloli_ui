# ailloli_ui_editor

Backend-neutral multi-paragraph and code-editor engine for Ailloli UI,
including optional Tree-sitter language integration.

This beta crate targets Rust 1.88. Most applications should consume editor
widgets through the `ailloli_ui` façade.
