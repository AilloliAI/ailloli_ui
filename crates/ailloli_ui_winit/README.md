# ailloli_ui_winit

Native `winit` windows, input dispatch, frame capture, and WGPU bootstrap for
Ailloli UI desktop applications.

This beta crate targets Rust 1.88. Most applications should use it through the
default feature set of the `ailloli_ui` façade.
