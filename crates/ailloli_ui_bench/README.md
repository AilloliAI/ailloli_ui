# ailloli_ui_bench

Versioned performance recording and regression gates for Ailloli UI. The
optional `cli` feature provides the `ailloli-ui-bench` command.

This beta crate targets Rust 1.88. See the repository benchmarking guide for
measurement and comparison policy.
