# ailloli_ui_openxr

Experimental OpenXR host integration for retained Ailloli UI scenes and input,
with optional WGPU and Vulkan targets.

This beta crate targets Rust 1.88. Its immersive APIs are experimental and may
change more quickly than the desktop façade.
