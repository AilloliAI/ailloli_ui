# Support

Ailloli UI is an early open-source project maintained on a best-effort basis.
There is no guaranteed response, resolution, maintenance, or compatibility
time for community requests.

## Community help

Use GitHub issues for reproducible bugs and focused framework feature requests.
Include the revision, Rust version, target platform, enabled features, minimal
reproduction, expected behavior, and actual behavior. Do not use issues for
vulnerabilities; follow [SECURITY.md](SECURITY.md).

Questions may receive an answer when maintainer or community capacity permits.
An issue's age, popularity, or author does not create a service commitment.

## Sponsorship

[GitHub Sponsors](https://github.com/sponsors/AilloliAI) is a voluntary way to
fund maintenance, bug fixes, performance work, documentation, features, and
stability. Sponsorship is not required for individual, commercial, or
open-source use allowed by the license.

Sponsors receive no private-repository access, exclusive feature, guaranteed
support time, bug priority, roadmap control, or technical decision right. See
[SPONSORS.md](SPONSORS.md) for the complete policy.

## Future commercial services

Professional support, integration, training, service-level agreements, and
custom development may be offered separately in the future under explicit
commercial contracts. Those services are not GitHub sponsorship rewards and
do not restrict access to essential framework code or fixes.
